## Quando falar com o suporte

- **Login, usuários, senhas, permissões por pessoa.** O acesso ao sistema é feito pelo
  auth-forward, que é gerenciado pelo suporte.
- **Ver os mesmos dados em mais de um computador**, ou colocar o sistema na internet. Os dados
  do MVP ficam só no computador de cada pessoa.
- **Erro grande**: o sistema não instala, não abre, o banco não carrega, o histórico do git
  ficou confuso, ou o Claude disse que o problema está na estrutura do projeto.

## O que mandar

O Claude prepara um **relatório para o suporte** — um bloco de texto pronto. Copie e mande
inteiro, junto com um print da tela, se houver. Não precisa explicar nada técnico.

> Este arquivo é protegido: só quem administra o projeto altera.
